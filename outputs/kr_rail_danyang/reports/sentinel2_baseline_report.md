# Sentinel-2 Baseline Screening Report - 한국철도공단 단양 매포

_생성일 2026-10-07 · Phase B · Sentinel-2 change candidate screening (Decision Support, 지장물/보상 판정 자료 아님)_

## Project

- 사업: 한국철도공단 토지보상 Demo / 중앙선 도담~영천 복선전철
- 대상 지역: 충청북도 단양군 매포읍 매포리·하괴리 일대
- 착공(context): 도담~안동 2015-05, 안동~영천 2015-11
- 복선 개통(context): 도담~안동 2022-07, 안동~영천 2024-12-21
- 위 날짜는 사업 개요 context이며 보상 기준일/법적 기준일/지장물 판정 기준일이 아니다.

## Objective

SkyWatch 50cm 아카이브 영상을 구매하기 전에 Sentinel-2 무료 영상으로 변화 Screening을 먼저 수행해 (1) 의미 있는 변화가 있었던 구역(hotspot), (2) 고해상도 영상을 확인할 ROI, (3) 구매를 검토할 촬영연도를 좁힌다.

- Sentinel-2 : **어디가 바뀌었는가?**
- SkyWatch 50cm(향후) : **무엇이 생겼고 없어졌고 형태가 어떻게 변했는가?**

## AOI

- 상태: **provisional (잠정)**
- geometry source: VWorld Data API LT_C_ADRI_INFO (법정리 경계) - 매포읍 매포리 + 하괴리 dissolve
- 면적: **6.08 km²** · CRS: EPSG:5186 (원본 VWorld EPSG:4326)
- 선정 근거: 잠정 AOI. 행정경계(법정리)이며 사업구역/보상구역 경계가 아니다. 사용자가 검토 중인 SkyWatch 검색 범위(약 22.3 km^2)의 geometry는 저장소에 없어 임의로 재현하지 않았다 (실측 AOI 면적은 outputs/kr_rail_danyang/reports/sentinel2_baseline_report.md 참고). 공식 SkyWatch 검색 geometry를 받으면 paths.aoi만 교체하면 된다.
- 철도 geometry: OpenStreetMap Overpass (railway=rail, 중앙선) - 공식 노선 geometry 아님

## Method

1. Imagery Provider(Sentinel-2) → AOI window 다운로드(cache) → 반사율 offset 보정/SCL 마스크 → 4-band 스택 GeoTIFF
2. 공통 전처리: EPSG:5186 재투영, 10m 공통 grid 정렬, AOI clip (`preprocessing.raster_preprocess.align_imagery_pair`)
3. 변화탐지: robust CVA + SSIM + edge/texture 앙상블, fixed threshold 0.5 (`change_detection.baseline`)
4. 후처리: morphology + 최소 면적 400 m², polygonize, ECC 정합 QA (`imagery_change_pipeline`)
5. Hotspot: 변화 polygon을 60 m 이내로 군집, 최소 1000 m². priority_score = 면적 × 점수 × 변화 빈도(step 쌍)
6. ROI: 추천 hotspot bounds + 300 m buffer, 한 변 500~1000 m
7. 촬영연도 제안: 인접 연도쌍(step)별 변화 면적이 최대 쌍의 25% 이상인 구간을 active로 보고 전/중/후 연도를 제안

## Limitations

- Sentinel-2 공간해상도는 10m이다 (1 pixel = 100 m²).
- 개별 지장물/소형 건물 판독용이 아니다.
- 모든 변화 후보는 고해상도 영상(SkyWatch 50cm 등)으로 검증해야 한다.
- change candidate ≠ 보상 대상 (지장물 존재/보상 여부 판정 아님).
- change candidate ≠ 불법/무허가 구조물.
- 계절·식생(경운/작황), 그림자, 영상 정합오차, 센서/궤도 차이가 오탐을 유발할 수 있다.
- '변화 없음'이 아니라 'Sentinel-2에서는 유의미한 변화가 검출되지 않음'으로 해석한다.
- Sentinel-2 공간해상도는 10m로 개별 지장물/소형 건물 판독용이 아니다.
- 본 결과는 change candidate / change hotspot이며 possible construction-related change일 뿐, 반드시 고해상도 영상(SkyWatch 50cm 등)으로 검증해야 한다.
- change candidate는 보상 대상 지장물이 아니며 불법/무허가 건축물도 아니다. 법적·행정적 판단은 본 Demo 범위 밖이다.
- 계절·식생(농경지 경운/작황), 그림자, 대기/센서 차이, 영상 정합오차가 오탐을 유발할 수 있다.
- '변화 없음'이 아니라 'Sentinel-2에서는 유의미한 변화가 검출되지 않음'으로 해석해야 한다.
- Sentinel-2는 2015-06 이후만 존재해 착공(2015) 이전 상태(2010~2015)는 이 Screening으로 확인할 수 없다.
