방법 요약
  • BSI = ((SWIR+RED) − (NIR+BLUE)) / ((SWIR+RED) + (NIR+BLUE)); SWIR=B11(20m), RED=B04, NIR=B08, BLUE=B02. 10m 밴드는 20m로 2×2 평균(4/4 유효), B11은 보간하지 않음.
  • NDVI·BSI는 이미 offset이 제거된 동일 장면 값을 사용하고 offset을 재적용하지 않음. NoData·구름 마스크는 결측으로 두며 변화 없음으로 취급하지 않음.
  • 변화 유형: 식생 감소 / 노출지 증가(NDVI↓+BSI↑) / 노출 지속 / 식생 회복(NDVI↑+BSI↓) / 안정 식생 / 불확실(상충·수체 의심). 변화 시점은 추정하지 않고 최초 관측 구간만 표기.
  • 채석장 확장 의심: 참조 폴리곤에 40m 이내로 연결된 노출지 증가 성분(2픽셀 이상). 채석 활동의 확정이 아니며 면적 변화 이력은 산출하지 않음.
  • 필지 통계: 필지∩픽셀 교차 면적 가중. NDVI(10m)와 복합(20m) 면적은 해상도가 달라 같은 정확도로 비교하지 않음. 식생 감소 ⊃ 노출지 증가(합산 금지).
